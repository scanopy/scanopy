This release focuses on making large networks easier to navigate — the topology canvas now reveals detail as you zoom, and Home is split into clearer Issues and Setup tabs.

## New Features

- Add zoom-aware topology rendering, so cards show full detail when you zoom in and simplify to readable names and labels when you zoom out across large estates.
- Split Home into separate Issues and Setup tabs, with issues grouped and paged by category so you can work through them without scrolling past setup steps.
- Add SNMPv3 DES privacy and Cisco AES-256 support, so more devices can be discovered without falling back to weaker credentials ([#846](https://github.com/scanopy/scanopy/issues/846)).
- Redraw diagram exports from the live canvas, fixing theme colors, badges, and Visio shapes so exports match what you see on screen.
- Read VLANs from TP-Link's private VLAN MIB, improving VLAN visibility on TP-Link switches.

## Improvements

- Speed up large topologies with faster panning, cached search, and indexed lookups, so views stay responsive as your estate grows.
- Show a staged progress bar while switching views or loading a site, instead of a blank canvas.
- Open large sites collapsed while remembering the containers you opened by hand, so you return to the layout you left.
- Report discovery shortfalls by cause and raise scan-performance conditions as warnings, making it clearer why a scan returned less than expected.
- Move Plans, Issues, Settings, and Setup into evenly spaced sidebar icons, and hide Setup and Issues on licensed self-hosted plans where they don't apply.
- Simplify the onboarding wizard with a single refusal notice, dismissible questions, and a credential step that appears after your first scan.

## Bug Fixes

- Fix late SNMP replies creating duplicate or incorrect device twins during a scan ([#848](https://github.com/scanopy/scanopy/issues/848)).
- Fix a crash in the node inspector when a selected node was no longer available.
- Fix the topology canvas overlapping banners instead of fitting below them.
- Fix Issue copy actions pasting placeholders rather than the real values and suggested fix.
- Fix cancel requests not reaching sessions the server had already ended.
- Fix dimming and transparency when opening a modal on top of an anchored one.
