Home has a new Issues tab: every problem Scanopy found across your sites, in one list, each with a button that opens its fix. Large topologies are much faster too. On a test site with about 4,300 hosts, panning the L2 view runs at 45 frames a second instead of 11, and search answers each keystroke in about 10 ms instead of over 100.

![The Issues tab, listing a daemon to upgrade, credentials whose target did not respond, devices that served less than they claimed, and hosts and subnets to review, grouped by category, each with its site and a button for its fix](https://scanopy.net/changelog/v0.20.0/issues-tab.png)

## Issues tab

- See every open problem in one table: daemons that need attention, credentials that didn't reach their target, devices that returned less than they advertise, scan warnings, and hosts and subnets known only from other devices' reports.
- Work through them by category (Daemons, Credentials, Devices, Scans, Review), and filter by site or by issue type.
- Fix each one from its row. The button opens the right place: upgrade the daemon, check the credential's target, change the scan setting, review the hosts.
- Get new warnings for conditions that slow a scan down or cut it short: a subnet larger than the ARP Scan Cutoff, a slow subnet with no daemon interface on it, a container network scanned over the network, a file-descriptor limit that throttled the deep scan, and ARP or ping unavailable to the daemon. Each names the setting to change.
- Count open issues from the sidebar's Issues icon. Setup steps move to their own tab.

## Faster topology at scale

Measured on the same 4,300-host test site:

- Pan the fully expanded L3 view, about 4,300 cards, at over 75 frames a second, up from about 2.
- Pan the Workloads view at 50 to 57 frames a second, up from 8 to 12.
- Search in 7 to 12 ms per keystroke, down from 92 to 142 ms.
- Reopen a view you've laid out before in under a second. Scanopy now stores the finished layout, so an unchanged view isn't laid out again. Reopening L2 took 4.2 s before.
- Zoom in for full detail on every card. Zoomed out, cards simplify to readable names, so a whole site stays legible at a glance.
- Open large sites collapsed, with the containers you opened by hand still open when you come back.
- Watch a staged progress bar while a view or site loads, instead of a blank canvas.

## New Features

- Read Cisco devices with AES-256 SNMPv3 credentials. Cisco derives the AES-256 key differently from net-snmp (LibreNMS lists it as AES-256-C), and Scanopy now tries both.
- Add DES privacy for SNMPv3 devices that support nothing stronger.
- Read VLANs and port membership from TP-Link's private VLAN MIB, for TP-Link switches that don't implement Q-BRIDGE ([#847](https://github.com/scanopy/scanopy/issues/847)).
- Redraw diagram exports from the live canvas, so draw.io and Visio files match what you see: theme colours, badges and card shapes.

## Improvements

- Move Plans, Issues, Settings and Setup into evenly spaced sidebar icons, and hide Setup and Issues on licensed self-hosted plans, where they don't apply.
- Simplify the onboarding wizard: one refusal notice, questions you can dismiss, and a credential step that appears after your first scan.
- Load each entity tab's filter options in one request instead of one per column.

## Bug Fixes

- Fix discovery sessions that never finished and blocked every scan queued behind them, and a daemon that stopped after enumerating its own interfaces ([#837](https://github.com/scanopy/scanopy/issues/837)).
- Fix a slow SNMP reply leaving the rest of that device's reads one answer behind, which dropped its LLDP neighbours and its links in L2 ([#848](https://github.com/scanopy/scanopy/issues/848)).
- Fix container and Proxmox collections that fell short being reported as timeouts. Each now says why, and a container whose inspect fails is no longer treated as removed.
- Fix cancel requests not reaching sessions the server had already ended.
- Fix a crash in the node inspector when the selected node was no longer available.
- Fix the topology canvas scrolling under the banner bar instead of fitting below it.
- Fix Issue copy actions pasting placeholders instead of the real values and suggested fix.
- Fix dimming and transparency when a modal opens on top of another.
