This release focuses on getting your device inventory right: you can now confirm inferred devices, and correct their details in place.

## New Features

- Add a resolve-first workflow for unconfirmed entities, so you can confirm or merge devices Scanopy inferred but couldn't verify.
- Edit device facts directly on the Details tab, including picking a device type from a searchable list.
- Search the Layer 2 topology by IP address to jump straight to the device you're looking for.
- Introduce the MCP Server page and beta program sign-up, so you can register interest in connecting Scanopy to AI assistants.
- Add a setting to disable the download gateway for locked-down deployments.

## Improvements

- Pin table headers in place while scrolling long lists of hosts, subnets, and daemons.
- Name each discovery run in your history after the discovery it came from, and show the exact command to pull daemon logs when a run fails.
- Show shared subnet ranges and list shared subnets first when sorting by site, with every Site column now sorting consistently by site name.
- Explain why a list action is unavailable instead of silently hiding it.

## Bug Fixes

- Fix forwarding-table hosts being reported under the wrong MAC address, which produced phantom neighbors in the topology.
- Fix stale port bindings so a rediscovered port correctly replaces an older address binding.
- Fix discovery sessions that could hang indefinitely by ending orphaned sessions and reporting stalls by name.
- Fix Bambu printer detection so its LAN ports are recognized alongside its certificate.
- Fix missing ports on inferred topology links.
