This release is focused on the topology map — Layer 2 rings now draw as actual loops, links are colour-coded by speed, and you can trace a path hop by hop from any link.

## New Features

- Draw rings of switches as loops in the L2 view, with ports ordered toward the links they carry and spurs stacked so cables don't cross; the layered layout still takes over when a ring can't be placed cleanly.
- Show every physical link on simplified maps, colour-coded by speed band, with a new Display toggle that controls whether container names appear when you zoom out.
- Trace a path link by link from the edge inspector, so you can follow a connection end to end without hunting across the map.
- Surface failed scans and silent daemons as Issues, complete with the scan's error message, and export your Issues list to CSV.
- Edit subnet ranges and VLAN links by hand, and record what each new subnet is for when you create it.
- Add a Water Utility demo site built on two fiber rings, so you can explore ring topologies without a live network.

## Improvements

- Cut the time it takes to open and first draw a large topology, and stop the topology list reloading every time you switch sites.
- Troubleshoot a specific daemon's connection from its own guided modal, including detection of daemons running inside WSL2.
- Link straight to the relevant documentation from warnings, the setup wizard and Issues, so fixes are one click away.
- Absorb inferred duplicate hosts automatically and offer a merge when a neighbour is ambiguous, with the host picker filtered to just the duplicates in question.
- Label unmatched switch ports as Unclaimed and tighten vendor matching, so device identification is less likely to guess wrong.
- Ask what you're setting up during signup and recommend a plan from your answer, with Community's seat and site limits spelled out.

## Bug Fixes

- Fix the topology viewport jumping when opening the details panel from a selection.
- Fix the topology failing to load when its tab is opened after the page has settled.
- Fix popovers staying open when clicking elsewhere on the topology canvas.
- Fix the load bar disappearing while a re-run was still pending.
- Fix dropdown options being truncated instead of sized to the longest choice.
- Fix a 0.0.0.0/0 interface being picked up as a subnet during discovery.
