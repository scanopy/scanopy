This release adds libvirt discovery and makes credentials easier to manage.

## New Features

- Add libvirt discovery over SSH, so KVM/QEMU hosts and their guests appear in your topology alongside other hypervisors ([#833](https://github.com/scanopy/scanopy/pull/833)).
- Split SSH credentials into logins and scripts, making it clearer which credential is used for access versus for running collection scripts.
- Group credentials by category so long credential lists are easier to scan.
- Show entity tooltips on references throughout the app, including host, service and site chips, with counts and the stale window at a glance.

## Improvements

- Clarify licensing: hints now link to the licensing guide, the Docker command for applying a key is spelled out, pasted keys with stray whitespace are accepted, and check-in failures explain what went wrong.
- Keep tags you create in the app wizard, and allow reusing the names of previously deleted tags.

## Bug Fixes

- Fix SSH logins using the wrong port and attempting connections to off-network addresses.
- Fix virtual machines being marked unreachable when their host NIC isn't visible to Scanopy.
- Fix modals flashing on page load and a missing backdrop when a stacked dialog closed.
- Keep the License Settings section collapsed across page reloads instead of reopening every time.
- Restore missing site and last-run details used by entity tooltips.
